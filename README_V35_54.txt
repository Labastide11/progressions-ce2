Progressions CE2 — V35.54 — Évaluations de mathématiques semestrielles

Règle verrouillée : enseignement -> entraînement -> évaluation quand la compétence est mûre -> éventuel réinvestissement plus tard.
On ne cherche pas à tout évaluer. Chaque fiche formelle cible 1 ou 2 compétences maximum. Les restitutions parents sont semestrielles (fin janvier/début février et fin juin).

Semestre 1 :
- P1 09/10 : PRO-P1-01 + OPE-P1-01 (problème / addition).
- P2 11/12 : NUM-P2-02 + OPE-P2-02 (numération / soustraction).
- P3 22/01 : TEM-P3-01 + GEO-P3-01 (temps / géométrie).
- P3 04/02 : CAL-P3-01 + OPE-P3-01 (tables / multiplication posée).

Semestre 2 :
- P4 23/03 : CAL-P4-02 + OPE-P4-02 (stratégies / division).
- P5 28/05 : FRA-P5-01 + MES-P5-01 (fractions / mesures).
- P5 04/06 : GEO-P5-01 + DON-P5-01 (géométrie / données).
- P5 11/06 : NUM-P5-01 + PRO-P5-02 (numération / problème complexe).

Les autres compétences restent suivies par entraînement, observations, traces formatives ou réinvestissements ; elles ne deviennent pas automatiquement des contrôles.
