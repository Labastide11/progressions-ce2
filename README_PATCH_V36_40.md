# PATCH V36.40 — Suggestions d’observations avec smileys

## Fichiers du patch
- `suivi-comportement.html`
- `suivi-comportement.css`
- `suivi-comportement.js`

## Modifications
Dans la fenêtre **Observation** du module **Suivi du comportement** :

- ajout de **smileys** dans les types d’observation ;
- ajout d’une zone **Observations rapides** ;
- ajout de **propositions prêtes à cliquer** pour remplir l’observation ;
- les propositions changent selon le type choisi.

## Exemples ajoutés
### Observation positive
- 🙂 Réponse pertinente à l’oral.
- 🙂 Participation orale active et pertinente.
- ✏️ Travail écrit soigné.
- ✏️ Écrit avec application.
- 🌟 S’applique sérieusement dans son travail.
- 🎨 Travail très soigné et bien dessiné.

### Avertissement / comportement à reprendre
- ⚠️ Parle sans arrêt malgré plusieurs rappels.
- ⚠️ Coupe la parole et interrompt les échanges.
- ⚠️ Ne respecte pas la consigne donnée.
- ⚠️ Gêne le travail de ses camarades.

### Observation neutre
- 📝 S’est davantage engagé après rappel.
- 📝 A eu besoin d’être relancé dans le travail.
- 📝 Efforts irréguliers au cours de la journée.

## Fonctionnement
- un clic sur une proposition l’ajoute dans la zone d’observation ;
- plusieurs propositions peuvent être combinées ;
- la page de suivi du comportement reste compatible avec le Google Sheet `comportement`.
