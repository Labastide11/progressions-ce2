Progressions CE2 — PATCH V34.70
Correctif global des rappels d’évaluation P1 → P5

Règle appliquée :
- Évaluation le lundi ou le mardi : le petit rappel est placé pendant le week-end précédent.
- Évaluation le jeudi ou le vendredi : le petit rappel est placé à partir du mardi ou du mercredi précédent.
- Évaluation juste après des vacances : la règle prévue reste le rappel pendant la deuxième semaine des vacances (aucun cas à déplacer dans le calendrier actuel).
- Jour J : aucun devoir ni révision supplémentaire ; l’Espace Parents affiche uniquement « Aujourd’hui : évaluation de… ».

Corrections :
- annonces détaillées replacées avant les évaluations sur P1 à P5 ;
- rappels du jour J supprimés et déplacés aux bons moments ;
- génération automatique des cartes informatives Jour J ;
- calendrier hebdomadaire alimenté par toutes les évaluations de l’année, même lorsque l’annonce se trouve dans la semaine précédente ;
- texte rassurant du bloc Évaluations mis à jour ;
- balises HTML <title> mises à jour en V34.70.
