V32.82 — Parcours individuel de l’élève

Nouveautés :
- vraie fiche individuelle modifiable par élève et par période ;
- réussites récentes sous forme d’entrées datées ;
- compétences maîtrisées reprises automatiquement depuis le suivi de classe ;
- besoins actuels ;
- objectifs prioritaires ;
- aides et accompagnements ;
- étapes et prochaines actions ;
- commentaires datés ;
- bilan de période ;
- résumé rapide avec compteurs et date de dernière modification ;
- enregistrement local automatique et bouton d’enregistrement manuel ;
- export JSON et impression/PDF ;
- migration des anciennes fiches locales V1 vers la nouvelle structure V2 ;
- clic sur une carte élève pour ouvrir directement son parcours ;
- bouton « Ouvrir son parcours » dans la vue détaillée par élève ;
- titre et caches mis à jour en V32.82.

La synchronisation distante de ces fiches n’est pas encore activée : les données sont conservées localement dans le navigateur.
