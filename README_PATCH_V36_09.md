# PATCH V36.09 — Récréation + Sciences P1 : eau et huile

Base : **V36.08**. Cette version remplace le précédent patch V36.09 non installé.

## Modifications

- Jeudi après-midi : récréation remise à **15h45–16h** dans le modèle hebdomadaire et les jeudis détaillés de P1.
- Créneaux du jeudi recalés : Sciences 14h15–15h, arts/chant 15h–15h45, récréation 15h45–16h, anglais 16h–16h25, français 16h25–17h.
- Sciences P1 : la séquence de 7 séances utilise désormais **l’eau et l’huile** comme support concret de la démarche scientifique.
- Séance 1 du jeudi 3 septembre : question explicite, hypothèses, expérience immédiate, observation et première conclusion dans la même séance.
- Séances 2 à 7 : question testable, protocole comparatif, mise en œuvre, trace d’observation, comparaison/conclusion et situation de référence.
- Cache de `emploi-du-temps-data-p1.js` actualisé en **36.09** pour forcer le chargement des nouvelles données.

## Installation

Copier les trois fichiers applicatifs du patch à la racine de Progressions CE2 en remplaçant les versions existantes.
