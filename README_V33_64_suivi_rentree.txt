# V33.64 — Suivi de rentrée dans Vue élèves

Ajout enseignant uniquement :
- bloc compact « Suivi de rentrée » dans Vue élèves ;
- suivi par élève : fiche de renseignements, assurance, coopérative ;
- coopérative : non remis / espèces / chèque / pas de participation ;
- montant, nom figurant sur le chèque et note libre ;
- bouton « Qui manque quoi ? » avec synthèse immédiate ;
- bouton « Copier la liste » pour les relances ;
- sauvegarde automatique locale, séparée par année scolaire ;
- aucune donnée envoyée vers Maître Hibou, Espace Parents ou Espace Remplaçant.

La correction V33.63 (portrait fille/garçon + date de naissance dans Vue élèves) est conservée.
