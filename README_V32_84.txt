V32.84 — Réussites récentes complètes

- Les dates techniques ISO sont affichées en français : jj/mm/aaaa à hh:mm.
- Le bloc Réussites récentes montre les 3 dernières réussites toutes catégories confondues.
- Sources prises en compte : entraînements, ceintures, records, activités de parcours et réussites saisies manuellement.
- Les ceintures restent également visibles dans Compétences maîtrisées.
- Les données distantes sont lues en une requête groupée via l’action API reussites.
