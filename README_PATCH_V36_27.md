# PATCH V36.27 — Anniversaires du mois dans « Ma classe »

Ajout sur la même ligne que :
**Matin · Après-midi · présents · absents**

d'un indicateur automatique :
**🎂 Anniversaires du mois : Prénom (le jour, âge ans)**

Exemple :
**🎂 Anniversaires du mois : Ritej (le 12, 9 ans) · Khadidja (le 17, 8 ans)**

Le jour et l'âge sont calculés automatiquement à partir de la date de naissance
des élèves et de l'année en cours. Les élèves sont classés par jour d'anniversaire.

S'il n'y a aucun anniversaire :
**🎂 Aucun anniversaire ce mois-ci**

- `index.html`
- `liste-eleves-popup.js`
