# V33.41 — Espace Parents compact

- Nouvelle page d'accueil Parents pensée pour smartphone.
- 4 accès rapides en grille 2×2 :
  🗓️ Emploi du temps
  📚 Devoirs
  🎒 Ce que nous apprenons
  💬 Infos de la classe (laissé en attente / désactivé)
- Une seule rubrique est affichée à la fois pour éviter le long scroll.
- Emploi du temps : si le parent ouvre la rubrique un jour de classe, le jour courant s'affiche directement.
  Exemple : mardi → emploi du temps du mardi immédiatement.
- Le mercredi, le week-end ou un jour sans classe : le prochain jour de classe est affiché.
- Toute la semaine reste accessible dans une zone dépliable.
- Bouton « ← Accueil Parents » dans chaque rubrique.
- Devoirs P1 V33.40 conservés à l'identique.
- Ajout de balises anti-cache dans parents.html et versionnement V33.41 des ressources.
