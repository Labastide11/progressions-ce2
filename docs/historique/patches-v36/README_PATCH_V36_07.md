# PATCH V36.07 — Maths : exemples concrets dans les déroulements

Fichiers à remplacer à la racine du projet :
- `emploi-du-temps-ui.js`
- `index.html`

## Modifications
- P1 : enrichissement des formulations trop vagues repérées dans les premières séances (compléments/doubles, nombre mystère, comparer/ranger, bilan, lecture-écriture-décomposition, stratégies de calcul).
- P2 à P5 : remplacement du déroulement enseignant générique par un déroulement construit à partir de la famille de notion et des exemples réels de la séance.
- Chaque étape du déroulement annuel contient désormais un exemple concret, un calcul, une situation, une correction ou une variable à modifier.
- Les exemples restent des repères : les nombres/données peuvent être changés selon la réussite des élèves.
- Aucun fichier de données élèves, Espace Parents ou Maître Hibou n'est modifié.

## Installation
Copier les deux fichiers modifiés à la racine du dépôt en remplaçant les versions existantes. Le `index.html` passe à V36.07 et force le rechargement de `emploi-du-temps-ui.js?v=36.07`.
