V36.01 — Cahier journal : vue semaine en ligne unique compacte

Modification validée :
- Dans « Cette semaine », chaque séance tient désormais sur une seule ligne.
- Structure : Matière · Activité · Statut.
- Les statuts restent modifiables via le menu déroulant.
- Récréation et pause méridienne restent sur une ligne simple centrée.
- La vue « Aujourd’hui » n’est pas modifiée.
- Objectif : pouvoir visualiser beaucoup plus de la semaine sans avoir à faire défiler verticalement.
