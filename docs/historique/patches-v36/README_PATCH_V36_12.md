# PATCH V36.12 — Explicitation pédagogique des mathématiques P1 → P5

Base attendue : V36.11.

## Modifications
- P1 : enrichissement des déroulements détaillés pour éviter les formulations télégraphiques ; chaque phase dispose d’un exemple ou d’un repère enseignant concret.
- Séance « Numération — Manipuler, lire et écrire des nombres » entièrement explicitée (326, variations C-D-U, exemples de lecture/écriture/décomposition, jeu du nombre caché, bilan).
- P2 à P5 : remplacement du guide annuel générique par des déroulements spécifiques à chaque famille de notions : numération, calcul mental, opérations, multiplication, division, fractions, durées, monnaie, mesures, géométrie, données et problèmes.
- Les exemples sont des variables de départ : ils peuvent être simplifiés ou complexifiés selon la réussite des élèves.
- Aucune modification des données élèves, de Maître Hibou, des devoirs ou de l’Espace Parents.

## Installation
Copier `index.html` et `emploi-du-temps-ui.js` à la racine du dépôt Progressions CE2 en remplaçant les fichiers existants.
