V35.91 — Cahier journal : correction définitive du bandeau des jours

Cause identifiée :
- le bandeau des jours de la vue semaine était encore sticky ;
- lors du défilement, il passait sous la barre de navigation du cahier journal ;
- le haut du texte LUNDI / MARDI / JEUDI / VENDREDI était donc masqué.

Correctif :
- suppression du comportement sticky du bandeau des jours ;
- jour + date conservés sur une seule ligne ;
- recentrage vertical et horizontal ;
- hauteur minimale sécurisée ;
- aucune modification des données ni des statuts.
