PATCH Progressions CE2 V34.10 — correction connexion API partagée

Cause corrigée : questions-eleves.js forçait encore l'ancien URL Apps Script V2.7.5 dans la clé localStorage partagée hibou_sync_api_url_v25754. Cela pouvait remplacer l'URL V2.8.0 puis rendre Vue élèves indisponible.

Installation :
1. Décompresser ce patch à la racine de Progressions CE2 V34.09.
2. Accepter le remplacement des fichiers.
3. Recharger la page d'accueil une fois, puis ouvrir Vue élèves.

Aucune modification Apps Script supplémentaire n'est nécessaire pour ce correctif si V2.8.0 est déjà déployée.
